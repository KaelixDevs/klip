# Changelog

## 1.0.0

Initial release of Klip, a Lua text clipboard history CLI for KDE Plasma Wayland.

- Watch clipboard changes through wl-clipboard.
- Search and select saved entries in a paginated terminal menu.
- Restore entries for pasting with Ctrl+V.
- List, add, delete, and clear saved text.
- Preserve multiline text, deduplicate entries, and bound disk usage.
- Skip clipboard events marked sensitive.
- Include isolated CLI tests and setup instructions for KDE shortcuts and autostart.
